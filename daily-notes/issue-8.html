Vue3 项目接入 Umami 统计与正式服务器部署完整指南 ​

原文地址

Vue3 项目接入 Umami 统计与正式服务器部署完整指南 | GitHub

本文适用于前端工程师，希望在 Vue3 项目中集成 Umami 进行页面 PV/事件统计，并在服务器上正式部署 Umami。本指南提供从前端接入到服务器部署的完整步骤，并保留服务器部署失败时的备选方案。

一、指南概览 ​

本文将引导你完成以下任务：

  1. 在 Vue3 前端项目中接入 Umami 统计
  2. 页面 PV 和事件埋点示例
  3. 在服务器上正式部署 Umami（Docker）
  4. 验证服务器上的 Umami 是否可用
  5. 备选方案：如果服务器部署失败，可先在本地部署再打包推送到服务器

二、Vue3 项目接入 Umami（HTML <script> 方式） ​

1️⃣ 在 public/index.html 中引入 Umami ​

html
<!-- public/index.html -->
<script async defer src="https://your-umami-domain.com/umami.js" data-website-id="xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"></script>
1
2

2️⃣ 页面 PV 自动统计（Vue3 Router 钩子） ​

js
// src/main.js
import { createApp } from 'vue';
import App from './App.vue';
import router from './router';

const app = createApp(App);

router.afterEach((to) => {
  if (window.umami) {
    window.umami.trackView(to.fullPath);
  }
});

app.use(router);
app.mount('#app');

3️⃣ 事件统计示例 ​

js
export default {
  methods: {
    trackBuy(productId) {
      if (window.umami) {
        window.umami.trackEvent('buy_click', { productId });
      }
    }
  }
}

三、正式服务器部署 Umami ​

1️⃣ 登录服务器并安装 Docker（如果未安装） ​

bash
ssh root@服务器IP
curl -fsSL https://get.docker.com | sh
systemctl start docker
systemctl enable docker
1
2
3
4

2️⃣ 创建 Umami 目录并进入 ​

bash
mkdir /opt/umami
cd /opt/umami
1
2

3️⃣ 拉取 Umami 和 PostgreSQL 镜像 ​

bash
docker pull docker.umami.is/umami-software/umami:latest
docker pull postgres:15
1
2

4️⃣ 创建 docker-compose.yml ​

yaml
version: "3.8"

services:
  db:
    image: postgres:15
    container_name: umami-db
    restart: always
    environment:
      POSTGRES_DB: umami
      POSTGRES_USER: umami
      POSTGRES_PASSWORD: umami_pass_123
    volumes:
      - ./data:/var/lib/postgresql/data

  umami:
    image: docker.umami.is/umami-software/umami:latest
    container_name: umami
    restart: always
    depends_on:
      - db
    environment:
      DATABASE_URL: postgres://umami:umami_pass_123@db:5432/umami
      UMAMI_DATABASE_URL: postgres://umami:umami_pass_123@db:5432/umami
    ports:
      - "3000:3000"

四、备选方案：本地部署再推送到服务器 ​

当服务器直接部署失败或拉取镜像超时，可以先在本地部署成功，再打包推送到服务器。

1️⃣ 本地部署 Umami ​

bash
mkdir umami
cd umami
1
2
  • 创建 docker-compose.yml（同上文配置）
  • 拉取镜像：
bash
docker pull docker.umami.is/umami-software/umami:latest
docker pull postgres:15
1
2
  • 启动容器：
bash
docker compose up -d
1
  • 首次启动会自动初始化数据库

2️⃣ 打包本地 Umami ​

bash
tar -zcvf umami.tar.gz umami
1

3️⃣ 上传到服务器 ​

bash
scp umami.tar.gz root@服务器IP:/root/
1

4️⃣ 服务器操作 ​

bash
ssh root@服务器IP
cd /root

# 解压
 tar -zxvf umami.tar.gz
 cd umami

# 启动 Umami
 docker compose up -d
